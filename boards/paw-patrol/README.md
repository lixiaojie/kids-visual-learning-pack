# 汪汪队任务指挥中心

面向 5–7 岁孩子和家长共学的互动式救援任务学习页。它把“喜欢角色”转成“理解分工、选择工具、复述流程”的练习。

## 已实现内容

- 首页任务指挥中心
- 7 个角色分工卡和详情
- 冒险湾地图热点
- 装备工坊和功能说明
- 今日任务小游戏
- 五步救援流程
- 故事复述训练
- 能力徽章收集，使用 localStorage 保存

## 本地开发

在项目根目录运行：

```bash
npm install
npm run dev
```

访问：

```text
http://127.0.0.1:5173/boards/paw-patrol/
```

构建检查：

```bash
npm run build:paw
npx tsc --noEmit
```

## 素材边界

页面不使用官方图片、Logo、剧照或品牌视觉资产。角色以文字、图标和原创控制台 UI 表达，定位为家庭教育原型。
